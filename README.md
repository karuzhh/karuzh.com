# Security Notice

Sensitive information should never be committed to a public repository.

Files such as these stay private:

```text
.env
.env.local
.env.production
credentials.json
database-backup.sql
private-key.pem
*.key
*.p12
secrets/
```

Public projects should use:

```text
.env.example
```

with placeholder values only.
